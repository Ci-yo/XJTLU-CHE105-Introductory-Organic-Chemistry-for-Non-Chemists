## 怎么使用

1. **平时学习**：打开 Lecture 目录，按 L1-L12 查看课件，再到 Tutorial 目录查阅对应答案。
2. **整理复习**：打开个人笔记目录，查看记忆、背诵和题型资料；需要查表时使用参考资料目录。
3. **考前练习**：先从历年试卷目录选择学年和 Final / Resit，练习后再查看考试笔记。批注属于复习记录，未作为标准答案校订。
4. **下载单个文件**：进入分类目录并点击文件名。PDF 可在线预览；文件页的下载按钮可保存原件。Word 和 PowerPoint 提供直接下载入口。
5. **下载全部资料**：点击仓库上方 **Code → Download ZIP**，解压后按文件夹查看。

私密审阅期间，需要登录有访问权限的 GitHub 账号。
