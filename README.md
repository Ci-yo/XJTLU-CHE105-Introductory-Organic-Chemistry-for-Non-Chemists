# CHE105

**Introductory Organic Chemistry for Non-Chemists**

西交利物浦大学 CHE105 个人学习资料，整理者 **Xiyao Chen / Ci-yo**。
当前为私密整理稿，包含 1 份个人笔记和 6 份历年试卷，供逐项审阅。

## 怎么使用

1. 查看笔记：点击下方“下载 Word 原稿”，保存后用 Word 或 WPS 打开。
2. 查看试卷：在下表选择学年，再点击期末或补考试卷，进入 PDF 预览；需要保存时，点击文件页的下载按钮。
3. 下载全部：点击仓库上方 **Code → Download ZIP**，解压后查看 `notes/` 和 `exams/`。

私密审阅期间，需要登录有访问权限的 GitHub 账号。
